One row per player. Headers are matched loosely — a name column (Player, Name, or First + Last), a team column, a position column, and optionally a rank column (Rank, Yahoo Rank, Overall…). If your workbook has multiple tabs, a sheet literally named All is used automatically. The picker and player pool always sort alphabetically by last name, regardless of rank — so a screen-visible draft board never gives away your priority order — but each player's rank still shows for your own reference.
